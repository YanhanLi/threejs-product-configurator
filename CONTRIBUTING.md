# Contributing

Thanks for taking a look. This is a small project, so the process is light.

1. Fork and create a branch.
2. `npm install`, then `npm run dev` while you work.
3. Before opening a PR, run:

   ```bash
   npm run lint
   npm run build
   ```

4. Keep changes focused and describe what you changed and why.

Bug reports and small feature ideas are welcome in the issues.
